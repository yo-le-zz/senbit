Server infrastructure, built around Linux.

Senbit is a lightweight, secure, server-first operating system. It keeps the Linux kernel and its software ecosystem, and adds a small Rust userspace on top.

What works today

Senbit installs itself to disk, boots, brings up the network and logs you in. It is developed and tested in QEMU, with BIOS and UEFI firmware. Physical hardware comes later.

Working

Implemented and tested in QEMU.

  • Linux kernel, Rust PID 1 (senbit-init) starting systemd
  • Interactive installer: BIOS and UEFI, MBR and GPT
  • DHCP or static network, chosen at install time
  • Users, password login, native sudo
  • Non-blocking boot with a boot report (bootreport)
  • apt install with Debian 12 packages
  • systemd services (systemctl, journalctl)

Written, not tested in a VM yet

Version 0.4.0 — system updates.

  • Updates through apt upgrade from a signed repository
  • Snapshot before each update
  • Automatic rollback after 3 failed boots
  • The rollback command

Built around the kernel, not instead of it

Senbit does not rewrite what Linux already does well. It keeps its own kernel configuration, patches only with a concrete reason, and puts its own work in the layers above.

Server applicationsDocker, nginx, databases and other Linux software. Nothing is installed by default.
Senbit userspaceRust: init, login, installer, native commands, and the devtool build tool.
System infrastructuresystemd, apt and dpkg, networking, updates and recovery.
Linux kernelProcesses, memory, networking, drivers, filesystems, security.
