Build it and run it

devtool checks your machine, downloads the pinned sources, builds everything and boots it in QEMU. It rebuilds only what changed.

Quick start

git clone https://github.com/yo-le-zz/senbit
./scripts/devtool.sh
./scripts/devtool doctor
./scripts/devtool install
./scripts/devtool run --force

Works on Fedora, Ubuntu/Debian and Arch. doctor lists what is missing, install installs it, and run builds and boots Senbit in QEMU (add --new for a blank disk).

What gets built

Linux kernelBusyBoxutil-linuxParted systemdapt / dpkgRust userspace native commandsrootfsinitramfsISO

devtool build package also builds the update packages and the APT repository (updates).

Test environment

  • x86_64 on Linux hosts
  • QEMU with BIOS firmware
  • QEMU with UEFI (OVMF) firmware

Contributing: read CONTRIBUTING.md. ARM64 and other architectures are planned once they add practical value.
