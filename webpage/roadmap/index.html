Roadmap

Organized by capability, not by date.

Phase 0 — Foundation 10/11

  • Build system and Linux kernel integration
  • Minimal root filesystem
  • Senbit PID 1 and QEMU boot
  • BIOS and UEFI boot
  • Installation system
  • User authentication
  • Basic networking and interactive shell
  • Native command system
  • Logging system
  • Shutdown infrastructure
  • Complete TTY and session management

Phase 1 — Server userspace 6/6

  • Native sudo and power-management commands
  • log command and Unix socket IPC
  • Service management (systemd, started by Senbit init)
  • systemctl and journalctl
  • Static networking
  • SSH (apt install openssh-server)

Phase 2 — Package ecosystem 5/5

  • Debian .deb as the package format
  • Debian package compatibility
  • Install, remove, update with apt
  • Dependency management
  • Repository management and package signatures

Phase 3 — System updates (not tested in a VM yet) 7/7

  • Version management and update detection
  • Download through apt upgrade
  • Integrity and authenticity verification (SHA-256, GPG)
  • Snapshot before update
  • Component-level updates (kernel and userspace packages)
  • Offline updates
  • Automatic rollback at boot, and the rollback command

Phase 4 — Snapshots and recovery 0/3

  • Snapshot system, configuration, package and service snapshots
  • Snapshot restoration and integrity verification
  • Recovery mode and boot recovery

Phase 5 — Security and monitoring 0/4

  • Firewall and Linux capabilities management
  • Security and service exposure auditing
  • File integrity tracking and security events
  • Configuration validation and hardening

Phase 6 — Deployment 0/4

  • Declarative configuration
  • Automated installation and configuration
  • Reproducible server deployment
  • Fleet management and remote administration

Phase 7 — Multi-architecture 1/3

  • x86_64
  • ARM64: kernel, userspace, initramfs, QEMU, images
  • Evaluate RISC-V and ARM32

Senbit — server infrastructure, built around Linux.
