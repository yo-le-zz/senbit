Installer

An interactive installer that asks everything first, writes nothing, and installs only after a final confirmation.

How an installation goes

  1. Questionskeyboard, disk and partitioning, accounts, hostname, language, timezone, network (DHCP or static address, gateway, DNS)
  2. Summaryeverything that will be done. Nothing has been written to the disk yet.
  3. DecisionCancel (the default), start over, or install
  4. Installationeach step is displayed as it runs, with its duration

Cancelling or starting over before the confirmation never modifies the disk.

What it sets up

Disks

Automatic or manual (fdisk) partitioning, or an existing partition. FAT32 for the EFI partition, ext4 for the root, then the bootloader.

Accounts

A root account and a main user, stored in /etc/passwd, /etc/shadow and /etc/group with hashed passwords.

System settings

Hostname, locale, timezone, keyboard layout and network are written to the target and persist across reboots.
