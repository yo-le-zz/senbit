# 🚀 Senbit 0.3.0

Senbit 0.3.0 is a major milestone for the project!

This release introduces a complete Debian package management ecosystem, significantly improves the installation experience, and fixes numerous system-level issues.

The goal is to make Senbit a more practical and reliable Linux server operating system while keeping it lightweight and efficient.

## 📦 Debian Package Ecosystem

Senbit now uses the standard Debian package management tools: **APT and dpkg**.

You can now:
- Install packages with `apt install`
- Remove packages with `apt remove` and `apt purge`
- Update package lists with `apt update`
- Upgrade installed packages with `apt upgrade`
- Automatically resolve dependencies
- Use official Debian repositories
- Verify package and repository signatures through APT

Debian package compatibility has also been improved, including merged-/usr, glibc, D-Bus, system accounts, and maintainer-script requirements.

No custom package manager or unnecessary wrapper: standard Debian tools are used directly.

## 🏗️ Installation Improvements

The installation workflow has been redesigned.

- Installation answers can now be reviewed and modified before confirmation.
- Selected components are installed together at the end of the installation instead of progressively.
- Improved installation progress reporting.
- Better error handling and installation reliability.
- Improved network configuration support.

## 🔧 System Improvements

- Numerous system integration fixes.
- Improved systemd integration.
- Better boot diagnostics with `bootreport`.
- Improved Debian compatibility.
- Networking and DHCP improvements.
- Various fixes targeting system reliability and usability.

## 🧪 Testing

Senbit 0.3.0 has been tested in a QEMU virtual machine.

- Successful system boot.
- Successful system restart.
- APT package installation tested.
- Git successfully installed through Debian repositories.

## ⚠️ Known Limitations

Docker Engine networking still has a known compatibility issue involving kernel Netfilter/NAT support in the tested environment.

Further testing and improvements are ongoing.
