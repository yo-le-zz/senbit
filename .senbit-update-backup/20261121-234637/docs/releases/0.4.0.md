# 🚀 Senbit 0.4.0

Senbit 0.4.0 adds **system updates**: the system can now update itself through the standard `apt`, with a snapshot before each update and an automatic rollback at boot.

This release also makes the build easier (automatic source download, progress display), cleans up a lot of dead code and rewrites the documentation.

The goal stays the same: a lightweight, reliable Linux server operating system built around standard tools.

## 🔄 System Updates

Senbit has **no update command of its own**: the system is updated with the real `apt`.

- `senbit-kernel` (kernel + init) and `senbit-userspace` (login, native commands, systemd units, scripts) are Debian packages published in a signed APT repository.
- Update them with `sudo apt update` and `sudo apt upgrade`, like any other package.
- Updates are **detected automatically** every day, and `bootreport` tells you at login: `N update(s) available`. Nothing is installed without you, and nothing is asked at boot.
- A **snapshot** is taken before each update (the last 3 are kept).
- The previous kernel and initramfs are kept: after **3 failed boots in a row**, GRUB starts the previous version by itself. It is also always available in the boot menu.
- Packages and repository are verified by APT (SHA-256 sums and GPG signature).
- Offline updates work with a plain `apt install ./package.deb` or a `file:` repository.

For maintainers: `devtool build package` builds the two packages and the APT repository, and a GitHub Actions workflow can publish it on GitHub Pages. See `docs/UPDATES.md`.

## 🛠️ Build and Tooling

- Missing or empty sources are downloaded automatically before each build (a fresh `git clone` now builds).
- `autogen.sh` is run for util-linux when needed.
- Long compilations show their progress (percentage or line count, elapsed time, last line) and the complete log of a failed step is kept in `build/logs/`.
- Parted is compiled in C17 so that it still builds with GCC 15.
- Kernel: nftables IPv4/IPv6 and NAT options required by Docker.
- QEMU uses `-cpu host`, which fixes "CPU ISA level is lower than required" for some binaries.
- CI no longer needs Git submodules.

## 🧹 Cleanup and Documentation

- Dead code and old scripts removed.
- The README is now short; the details moved to `docs/` (architecture, installer, running system, development, roadmap, updates).
- `devtool` and `scripts` documentation rewritten in English and French.
- Smaller pull request template.

## 🧪 Testing

- The build succeeds in GitHub Actions.
- **The update chain (repository, `apt upgrade`, snapshot, rollback) has not been tested in a virtual machine yet.** It was written and reviewed carefully, but expect fixes.

## ⚠️ Known Limitations

- Rollback: once the previous version has booted successfully, the boot counter is reset and the next boot tries the new version again. Use `sudo apt-mark hold senbit-kernel` until a fixed version is published.
- Docker Engine networking depends on the rebuilt kernel (overlayfs and nftables) and is not confirmed yet.
- The update repository must be signed, and the image must contain the matching public key; an unsigned repository is for local tests only.

Further testing and improvements are ongoing.
