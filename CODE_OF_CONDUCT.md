# Code of Conduct 🦀

Senbit is an open-source project built by and for people who want to create reliable server infrastructure.

We want the project to be a welcoming, constructive, and technically focused community for everyone who participates.

By participating in Senbit, you agree to follow this Code of Conduct.

---

## 🤝 Our Standards

We expect all community members to:

- Be respectful toward other contributors.
- Discuss ideas and technical decisions in good faith.
- Focus criticism on ideas, code, designs, and decisions rather than people.
- Assume good intentions while remaining open to correcting misunderstandings.
- Give useful and constructive feedback.
- Respect different levels of experience.
- Accept that technical disagreements are normal.
- Keep discussions focused and productive.
- Give credit where credit is due.
- Respect the licenses and work of other projects.
- Follow the project's security and contribution guidelines.

Being technically correct does not justify being disrespectful.

---

## 💬 Technical Discussions

Senbit is an engineering project, and disagreements about architecture, implementation, performance, security, or design are expected.

Healthy disagreement is encouraged.

For example, it is completely acceptable to say:

> "I don't think this approach will scale well because..."

or:

> "This could introduce a security problem because..."

It is not acceptable to turn technical disagreement into personal attacks.

Focus on:

```text
Problem
   ↓
Evidence
   ↓
Technical reasoning
   ↓
Alternative
   ↓
Solution
````

Not:

```text
Disagreement
   ↓
Personal attack
```

---

## 🚫 Unacceptable Behavior

The following behavior is not acceptable:

* Harassment or intimidation.
* Personal attacks.
* Insults directed at contributors.
* Discriminatory or hateful comments.
* Threats of violence.
* Deliberate disruption of discussions or development.
* Repeatedly targeting an individual.
* Sharing someone's private information without permission.
* Sexual harassment or unwanted sexual content.
* Deliberately impersonating another contributor.
* Maliciously submitting harmful code or content.
* Deliberately hiding security vulnerabilities from maintainers in order to harm users.
* Any other behavior that would reasonably make participation unsafe or hostile.

---

## 🔐 Security Discussions

Security vulnerabilities must be handled according to [`SECURITY.md`](SECURITY.md).

Do not publicly disclose sensitive vulnerability information before giving maintainers an opportunity to investigate.

Do not use security research as a reason to target, harass, or threaten other community members.

Responsible security research is welcome.

---

## 🧑‍💻 Contributions

Contributors are expected to take responsibility for the changes they submit.

This includes:

* Reviewing submitted code.
* Understanding the code being contributed.
* Testing changes where possible.
* Following project conventions.
* Respecting licensing requirements.
* Being honest about testing and limitations.

AI-assisted development is allowed.

However, using an AI tool does not remove the contributor's responsibility for the code they submit.

---

## ⚖️ Enforcement

Maintainers are responsible for enforcing this Code of Conduct within Senbit's official community spaces.

Depending on the situation, maintainers may:

1. Ask participants to stop inappropriate behavior.
2. Request clarification or correction.
3. Remove inappropriate content.
4. Temporarily restrict participation.
5. Permanently restrict participation in the community.

The response will depend on the severity and circumstances of the behavior.

Maintainers may take action when behavior violates this Code of Conduct even if it does not fit into one specific example listed above.

---

## 📢 Reporting Problems

If you experience or witness behavior that violates this Code of Conduct, report it privately to the project maintainers.

Do not use public Issues or Discussions to publicly accuse or harass another community member.

When making a report, provide:

* What happened.
* Where it happened.
* When it happened.
* The people involved, if relevant.
* Any relevant messages or evidence.

Please avoid sharing unnecessary private information.

---

## 🧭 Scope

This Code of Conduct applies to:

* GitHub Issues.
* GitHub Discussions.
* Pull Requests.
* Code reviews.
* Project documentation.
* Official Senbit communication channels.
* Other spaces where someone is officially representing the Senbit project.

---

## 🌱 Good-Faith Participation

Senbit is an evolving project.

People will make mistakes.

Technical decisions will sometimes be changed.

Features will sometimes be rejected.

Pull Requests will sometimes need substantial changes.

That is normal.

The goal is to solve problems together rather than turn disagreements into conflicts.

---

## 🦀 Final Principle

Build the software.

Challenge the ideas.

Improve the design.

Respect the people.

**Senbit is built in the open, and everyone participating in good faith should have a place to contribute.** 🚀
